# Deployment & Submission Guide

## 1. GitHub repository (required link)
1. Create a new **public** repo on github.com (e.g. `care-transition-analytics`).
2. In this project folder run:
```bash
git init
git add .
git commit -m "Care Transition Efficiency & Placement Outcome Analytics"
git branch -M main
git remote add origin https://github.com/<your-username>/care-transition-analytics.git
git push -u origin main
```
(Or upload the files through GitHub's web "Add file → Upload files".)
Your **GitHub link** = `https://github.com/<your-username>/care-transition-analytics`

## 2. Deployed project link (Streamlit Community Cloud)
1. Go to https://share.streamlit.io and sign in with GitHub.
2. **Create app** → choose your repo, branch `main`, main file `app.py`.
3. Click **Deploy**. After ~2 minutes you get `https://<name>.streamlit.app`.
Paste that URL into the README and the submission form.

## 3. Research paper link
Upload `reports/Research_Paper.docx` (add your name on the title page first) to Google Drive → Share → "Anyone with the link can view", or push it to GitHub and use the file's GitHub URL.

## 4. Videos (record yourself)
Use `docs/VIDEO_SCRIPTS.md`. Record with Zoom/Meet/Loom/OBS, upload to YouTube (Unlisted) or Google Drive (anyone with link), and paste the https:// link.

## Final checklist
- [ ] Your name replaced in the paper and executive summary
- [ ] GitHub, Streamlit, paper, project-video, internship-video links all start with https://
- [ ] Links open in a private/incognito window
